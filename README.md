# java-racingcar-precourse

### 요구사항
#### 0. SRP 준수

#### 1. 입력
- 자동차 이름(쉼표로 구분, 5자 이하만 가능)
- 이동 횟수(정수)
- 컬렉션 활용하여 쉼표로 구분

#### 2. 난수 생성
- 0~9 사이 무작위 값 생성

#### 3. 전진 조건 판단
- 난수가 4 이상일 경우 전진

#### 4. 출력
- 차수별 실행 결과 출력
- 이름과 -로 표현

#### 4. 최종 우승자 이름 출력
- 우승자가 여러 명일 경우 쉼표로 구분

#### 5. 예외 처리
- 자동차 이름 5자 초과
- 자동차 이름 문자열 이외의 값
- 이동 횟수 숫자 이외의 값
